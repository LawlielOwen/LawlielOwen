### 🧑‍💻 Sobre mí

Soy **Técnico Superior Universitario en Desarrollo de Software Multiplataforma** y actualmente curso la **Ingeniería en Desarrollo y Gestión de Software**.

💻 **Mi enfoque:** desarrollo de software Full Stack y multiplataforma, utilizando tecnologías como Angular, Node.js, TypeScript, Java y bases de datos SQL/NoSQL.

🚀 **Experiencia:** desarrollo y despliegue de aplicaciones web, integración con bases de datos, automatización de procesos y configuración de entornos de producción con Ubuntu Server, Nginx y PM2.
